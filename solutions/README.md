## Running the code

Every complete query and script printed in these solutions is also in a file you can run:

| File | What it holds |
|---|---|
| `sql/ch17_13_solutions.sql` | Every SQL query in the solutions (SQL Server) |
| `sql/sqlite_version/ch17_13_solutions.sql` | The same queries for SQLite |
| `python/ch18_11_solutions.py` | Every Python script in the solutions |

Partial lines that the solutions show to explain one change (a single `AND`, a `CASE` branch) are not in the files; the complete query that contains them is.
